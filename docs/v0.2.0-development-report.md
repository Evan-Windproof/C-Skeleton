## 最终验证

- **安装与构建**通过 npm ci、TypeScript 类型检查、Vite 开发入口测试与生产构建。Chromium 使用实际生产产物验证 /C-Skeleton/ 子路径，脚本、样式和 SVG favicon 均可加载，返回桌面链接的目标也通过了导航测试。
- **Vitest 15 项通过**。覆盖模块顺序、全局 ID 唯一性、模块与课程关联、有效答案和错误选项反馈、每节题数、分模块及总体统计、旧存储和异常存储。
- **Playwright Chromium 10 项通过**。遍历 54 节、162 道题并检查所有选项。每题验证一次错误反馈、重答和正确反馈。验证了跨模块上一节与下一节、已完成标记、两种模式、深浅主题、刷新恢复、继续学习、复制和 320px 布局。
- **GCC 14.2.0 验证 105 个完整程序**。以 C11、Wall、Wextra、Wpedantic 和 Werror 逐个编译，用示例输入运行并核对输出。105 个程序也通过了 AddressSanitizer 和 UndefinedBehaviorSanitizer 运行。
- **27 道输出预测题**用 C11 程序核对了输出或读取结果。额外核对了头文件重复包含、分文件编译链接、ELF 节、汇编生成和 GNU 链接脚本符号。

## 兼容与发布边界

- v0.1 的 localStorage 键、指针课路由、题目 ID 和选项 ID 均沿用。同一站点下的旧记录可以原样读取并计入总体与模块统计。
- 三处依赖其他文件或链接配置的示例都在页面注明需要配合使用。C11 示例脚本单独验证可以直接编译运行的程序。
- GitHub Pages 工作流沿用现有配置。远端现有提交 d66fb8b 的部署工作流已成功。本次 v0.2.0-dev 在工作区通过构建和子路径验证，正式版本待发布。 [GitHub Actions](https://github.com/Evan-Windproof/C-Skeleton/actions/runs/44520346324)
